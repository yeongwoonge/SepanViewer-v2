# 세판뷰어 v2 타이밍 안내

## 측정 기준

캡처한 노트의 중심 위치와 이동 속도로 판정선 중심에 닿을 시각을 추정하고, 키를 누른 시각과 비교합니다. 음수는 FAST/EARLY, 양수는 SLOW/LATE입니다. 게임 내부 채보·판정 시각·FAST/SLOW·RATE를 직접 읽지 않습니다.

판정선 기본 위치는 1080p 기준 y=750입니다. 기어 위치는 좌·중앙·우 프리셋으로 선택합니다. 이미지 프리셋은 검은 배경에서 분리한 노트 모양의 중심을 기준으로 사용합니다.

원본 판정 계산 방식과 글로벌 보정 −5ms를 유지합니다. 글로벌 보정은 노트 예상 도달 시각에 더하므로 −5ms는 표시 오차를 +5ms 방향으로 이동시킵니다. 이 값이 모든 PC에서 정확한 보정값이라는 뜻은 아닙니다.

## 게임 판정 타이밍

설정 창의 게임 판정 타이밍은 사용자가 실제 게임과 동일하게 입력합니다. 배포 기본값은 0이며 게임 설정을 변경하지 않습니다.

현재 모델은 입력한 판정값에 단위당 1ms를 적용하지만, 게임 내부 판정 설정의 정확한 환산 단위는 공식적으로 확인하지 못했습니다. 노트 출력 타이밍의 ms 단위와 게임 판정 설정 단위는 별개입니다.

결과에는 측정 당시 설정을 보관합니다. 이후 설정을 바꿔도 이미 저장된 과거 결과의 값은 바뀌지 않습니다.

## 통계와 추천

일반 레인의 −42ms 미만은 얼리, −42~+42ms는 퍼펙, +42ms 초과는 레이트로 집계합니다. ±21ms 가이드를 함께 표시합니다. 롱노트 떼기는 분석하지 않습니다.

한 판 후보는 범위 내 개수를 우선하고 동률이면 받아들인 입력의 최소 경계 여유를 최대화합니다. 평균·중앙값을 그대로 추천하지 않습니다.

전체 통계는 측정 조건이 맞는 판을 현재 설정 기준으로 환산한 뒤 판별 범위 내 비율을 동일 비중으로 최대화합니다. 합계 범위 내 개수는 현재 설정보다 줄어들지 않도록 제한합니다. 동률은 경계 여유로 구분합니다.

판별 제외 비교와 시간순 전진 비교를 함께 계산합니다. 6판 미만은 잠정 후보이고, 이후에는 두 비교의 평균 이득이 양수인 경우만 후보를 유지합니다. 시간순 확인 판의 이득을 판 단위로 1,024회 재표본한 하한도 양수이면 ‘반복 기록 지지’로 표시합니다. 이득이 불명확하면 ‘현재 유지’를 표시합니다. 고정 시드를 사용하며 각 비교는 최대 24판으로 제한합니다.

이 비교는 저장된 화면 오차를 평행 이동하는 모델입니다. 실제 재플레이나 게임 RATE의 개선을 검증한 것은 아니며 게임 판정 1단위의 ms 환산도 아직 모델 가정입니다. 추천값은 자동 적용하지 않습니다. 과거 저장된 한 판 PNG는 자동으로 덮어쓰지 않으며, 전체 통계를 다시 계산하면 새 방식을 사용합니다.

## 캡처와 결과 저장

노트 캡처 목표는 60fps이며 실제 처리율은 다를 수 있습니다. 판정 계산식과 입력 수집 경로는 유지합니다.

결과 감지는 작은 글자 두 영역을 초당 5회 확인합니다. 기존의 고정 700ms 확인에 더해, 첫 감지 후 최소 1초와 글자 밝기가 0.4초 동안 안정된 것을 확인한 뒤 결과 이미지를 확정합니다. 움직임이 끝나지 않으면 2.5초로 대기를 제한합니다. 이 확인은 기존 두 영역을 재사용하며 전체 화면 분석을 추가하지 않습니다.

첫 안전한 결과 이미지를 보관하고, 페이드가 밝아지면 중간 후보를 한 번 갱신합니다. 더 어두운 최종 후보로 밝은 이미지를 덮어쓰지 않습니다. 알트탭하면 확보한 후보로 저장을 마칠 수 있지만 결과를 보기 전에 가린 화면을 추측해 저장하지는 않습니다.

결과 화면과 이미지가 이미 확인된 뒤 F5를 누르면 그 판을 먼저 저장하고 재시작합니다. 결과를 확인하기 전의 F5는 기존처럼 진행 시도를 버립니다. 설정 변경·정지는 진행 시도를 초기화합니다.

방법의 일반 원칙 참고: [시간순 분할](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html), [그룹을 나눈 교차 비교](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html). 해당 라이브러리를 런타임 의존성으로 추가하지 않았습니다.
