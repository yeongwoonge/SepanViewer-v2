# 세판뷰어 v2 타이밍 안내

## 측정 기준

캡처한 노트의 중심 위치와 이동 속도로 판정선 중심에 닿을 시각을 추정하고, 키를 누른 시각과 비교합니다. 음수는 FAST/EARLY, 양수는 SLOW/LATE입니다. 게임 내부 채보·판정 시각·FAST/SLOW·RATE를 직접 읽지 않습니다.

판정선 기본 위치는 1080p 기준 y=750입니다. 기어 위치는 좌·중앙·우 프리셋으로 선택합니다. 이미지 프리셋은 검은 배경에서 분리한 노트 모양의 중심을 기준으로 사용합니다.

원본 판정 계산 방식과 글로벌 보정 −5ms를 유지합니다. 글로벌 보정은 노트 예상 도달 시각에 더하므로 −5ms는 표시 오차를 +5ms 방향으로 이동시킵니다. 이 값이 모든 PC에서 정확한 보정값이라는 뜻은 아닙니다.

## 게임 판정 타이밍

설정 창의 게임 판정 타이밍은 사용자가 실제 게임과 동일하게 입력합니다. 배포 기본값은 0이며 게임 설정을 변경하지 않습니다.

현재 모델은 입력한 판정값에 단위당 1ms를 적용하지만, 게임 내부 판정 설정의 정확한 환산 단위는 공식적으로 확인하지 못했습니다. 노트 출력 타이밍의 ms 단위와 게임 판정 설정 단위는 별개입니다.

결과에는 측정 당시 설정을 보관합니다. 이후 설정을 바꿔도 이미 저장된 과거 결과의 값은 바뀌지 않습니다.

## 통계와 추천

일반 레인의 입력을 기준으로 −42ms 미만은 얼리, −42~+42ms는 퍼펙, +42ms 초과는 레이트로 집계합니다. ±21ms 가이드를 함께 표시합니다. 사이드와 트리거는 별도 레인으로 표시할 수 있으며 일반 입력 통계와 구분합니다.

추천 후보는 허용된 게임 판정값 범위에서 일반 ±42ms 또는 하드 ±21ms 안의 입력 수를 최대화합니다. 동률이면 현재 설정에서 변화가 적은 값을 우선합니다. 표본 수·매칭 비율·분산 등 조건을 충족하지 않으면 추천을 보류합니다. 평균 오차를 그대로 추천값으로 쓰지 않습니다.

화면 측정의 추천과 실제 게임 RATE는 같지 않습니다. 후보값은 자동 적용하지 않습니다. 결과 창에서 실제 RATE를 입력해 조건이 같은 여러 판을 비교할 수 있습니다.

## 캡처와 결과 저장

노트 캡처 목표는 60fps입니다. 실제 주기는 PC 부하·화면 전환 등에 따라 달라질 수 있으며 설정값만으로 실제 60fps를 보장하지 않습니다. 진단 로그의 `CAPTURE — actual / target`과 처리 시간을 확인합니다.

결과 감지는 작은 글자 영역 두 곳을 초당 5회 확인합니다. 결과를 안정적으로 확인하면 저장하며, 확보한 결과 이미지가 있으면 알트탭 직후에도 완료할 수 있습니다. 게임이 다른 창에 가려졌을 때 다른 앱의 화면을 결과로 캡처하지 않도록 가림 여부를 확인합니다.

결과를 한 번도 확인하지 못한 상태에서는 비활성화만으로 완료를 추정하지 않습니다. 게임 결과 화면으로 돌아와야 저장할 수 있습니다. F5·정지·설정 변경은 진행 시도를 초기화합니다.
