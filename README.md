# 세판뷰어 v2

원본: [wtre/SepanViewer](https://github.com/wtre/SepanViewer)

원본 세판뷰어를 개인적으로 사용하려고 일부 기능과 설정을 수정한 비공식 개인 수정본입니다. 노트 이미지 프리셋, 키 설정, 게임 위 오버레이와 한 판 결과 통계를 추가했습니다.

## 주요 변경점

- **가로형 오버레이 추가** — 세로형 외에 기어 안에 둘 수 있는 가로형을 추가했습니다. OBS 없이 표시하며 위치·크기·투명도를 조절할 수 있습니다.
- **노트 이미지 프리셋** — HUD 설정 화면 이미지를 불러오거나 붙여넣어 노트 모양·색상과 기어 폭을 설정할 수 있습니다.
- **버튼 수별 키 설정** — 4·5·6·8키의 배치를 각각 저장하고, 키 칸을 클릭한 뒤 실제 키를 눌러 지정할 수 있습니다.
- **한 판 기록·통계 이미지 저장** — 결과 화면을 감지해 곡명·난이도·시각별로 저장하고, 타이밍 분포와 레인별 통계를 그래프로 남깁니다.
- **판정 분석·추천 후보 표시** — 얼리·퍼펙·레이트와 ±42ms / ±21ms 기준선을 표시하고, 각 범위에 맞춘 판정 설정 후보를 제공합니다.

## 실행 및 기본 설정

1. **Windows 11 / Python 3.12 x64** 환경에서 사용합니다. Python Launcher를 포함해 설치한 뒤, 저장소를 내려받아 압축을 풀고 `install.bat` → `start.bat` 순서로 실행하세요. 최초 설치에는 인터넷이 필요합니다.
2. 게임을 **1920×1080 또는 2560×1440 전체 창 모드**로 실행하세요.
3. 기본 프리셋은 **4키 · 가운데 기어 · CYTUS 노트 · 게임 판정 타이밍 0**입니다. 일반 키는 **S / D / K / L**, 사이드는 **왼쪽 Shift / 오른쪽 Shift**입니다.
4. 게임 창을 선택하고 **설정**에서 버튼 수별 키 배치, 기어 위치, 판정 타이밍을 실제 게임과 맞춘 다음 **시작**을 누르세요.
5. 다른 노트 스킨은 **설정 → 노트·색 프리셋**에서 HUD 설정 화면 이미지를 불러오거나 Ctrl+V로 붙여넣어 지정할 수 있습니다.

OBS 없이 오버레이를 표시할 수 있고, 결과 화면을 확인한 판의 통계는 `records/버튼 수 난이도 곡명/기록 시각/`에 저장합니다. **F5는 현재 시도를 초기화하며 중도 재시작한 판은 저장하지 않습니다.**

## 참고

화면과 입력을 바탕으로 계산하므로 **실제 게임 판정과 일부 오차가 생길 수 있고, 스킨이나 효과에 따라 일부 노트는 인식하지 못할 수 있습니다.** 추천 판정은 참고용이며 게임 설정에 자동 적용하지 않습니다.

주로 4키로 확인했으며 5·6·8키는 시험 기능입니다. 롱노트 유지·떼는 판정은 분석하지 않습니다.
